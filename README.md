# TontooAccessibility

A simple Rust internationalization (i18n) library for embedding translations in other projects.

## Made for TontooOS

Explore more at https://github.com/TontooOS/Libs

## Adding to Your Project

Add to your `Cargo.toml`:

```toml
[dependencies]
accessibility = { path = "/Library/System/accessibility.library" }
```
